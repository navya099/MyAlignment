# MyAlignment 사용 설명서

MyAlignment는 평면선형과 종단을 Python에서 정의하고, 어셈블리를 따라 배치해 코리더와 표면을 만드는 라이브러리입니다. 철도 선형의 캔트와 분기기, 부지 정지, 토공량 및 DXF 출력도 같은 데이터로 연결할 수 있습니다.

처음 사용한다면 [시작하기](getting-started.md)에서 선형과 종단을 하나의 코리더로 연결하고 2D·3D DXF를 생성해 보세요. 각 가이드의 Python 예제는 별도 파일로 저장해 실행할 수 있습니다.

| 하려는 작업 | 가이드 |
| --- | --- |
| PI 좌표로 선형을 만들고 측점·횡거를 조회하기 | [평면선형](alignment.md) |
| 설계·현황 종단을 정의하고 구배·표고 및 밴드 표시하기 | [종단과 종단 뷰](profile.md) |
| 철도 궤도, 캔트, 분기기와 시저스 크로스오버 다루기 | [철도와 분기기](rail.md) |
| 차로·사면을 조립하고 기준선별 코리더 및 횡단면 만들기 | [어셈블리와 코리더](corridor.md) |
| TIN 경계·브레이크라인·형상선과 부지 정지 다루기 | [지표면과 정지](surface.md) |
| 포장 면적·체적과 절·성토량 계산하기 | [수량 산출](quantities.md) |
| 스타일·레이블을 적용하고 DXF나 HTML 출력하기 | [도면과 3D 출력](rendering.md) |

import 경로를 찾고 있다면 [모듈 찾아보기](modules.md)를 참고하세요.
